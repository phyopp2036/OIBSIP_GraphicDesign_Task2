Task 2: Logo Design - Golden Five

Objective:
To design a luxury logo and visual identity for a premium tile and home interior shop.

Tools Used:
Canva

Steps Performed

Background: I used a dark background with shiny gold sparkles and lights to make the design look premium.

Gold Frame: I added a gold square box in the center to help people focus on the logo.

Logo Design: I drew a simple house symbol using clean gold lines to represent modern home interiors.

Shop Name: I wrote the shop name "GOLDEN FIVE" in a bold, bright gold font so it stands out clearly.

Tagline: I put the shop motto "PERFECT TILES. PERFECT HOMES." at the bottom in clean black text so it is easy to read.

Layout Balance: I arranged the symbol and text neatly inside the box so everything looks clean and centered.
